Credential Connections style guide

The source of truth for every Credential Connections prototype. Everything on this page renders live from tokens.css and components.css, the same files the prototypes load, so it always shows the current system.

Tokens Foundation: Untitled UI Typeface: Inter Standard: WCAG 2.2 AA

Color

The badge on each swatch shows its contrast with white text. AA (4.5:1 or more) is safe for body text; AA large (3:1 or more) only for text 18px+ or bold 14px+, and for icons.

Typography

Inter on the Untitled UI scale. Display sizes are for headlines; body sizes cover everything else.

Weights

Regular 400 Medium 500 Semibold 600 Bold 700

Spacing

A 4-point scale. Padding, gaps and margins should land on one of these steps.

Radius

--radius-md (8px) is the default for buttons and inputs; --radius-xl (12px) for cards.

Elevation

Cards sit at --shadow-xs. Menus and popovers use --shadow-lg; modals use --shadow-xl or higher.

Buttons

One primary action per view. Use secondary for the alternatives, and tertiary for low-emphasis actions such as "Cancel". Use extra small only in dense spots such as table rows and inline actions.

Inputs

40px tall with an inset 1px border, so the field doesn't shift when the error border appears.

Badges

Pill shaped, 12px text. Each status uses its 50 tint for the fill, 200 for the border and 700 for the text.
