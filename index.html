Credential Connections style guide

The source of truth for every Credential Connections prototype. Everything on this page renders live from tokens.css and components.css, the same files the prototypes load, so it always shows the current system.

Tokens Foundation: Untitled UI Typeface: Inter Standard: WCAG 2.2 AA

Color

The badge on each swatch shows its contrast with white text. AA (4.5:1 or more) is safe for body text; AA large (3:1 or more) only for text 18px+ or bold 14px+, and for icons.

Elevation

Cards sit at --shadow-xs. Menus and popovers use --shadow-lg; modals use --shadow-xl or higher.

Radius

--radius-md (8px) is the default for buttons and inputs; --radius-xl (12px) for cards.

Spacing

A 4-point scale. Padding, gaps and margins should land on one of these steps.

Text styles

Classes for headings and body text, so pages don't set font sizes by hand. Headings are semibold; body text is regular. Each uses the matching size and line-height tokens.

Typography

Inter on the Untitled UI scale. Display sizes are for headlines; body sizes cover everything else.

Weights

Regular 400 Medium 500 Semibold 600 Bold 700

Buttons

One primary action per view. Use secondary for the alternatives, and tertiary for low-emphasis actions such as "Cancel". Use extra small only in dense spots such as table rows and inline actions.

Target sizeExtra small (32px) is the smallest button. Nothing interactive goes below 24 × 24px (WCAG 2.2, 2.5.8).

Icon buttons

For actions shown as an icon only. Always give them an aria-label and a tooltip. 36px by default; cc-icon-btn--xs (32px) for table rows; cc-icon-btn--lg (44px) for headers and touch.

Links

Brand links use --blue-800 (it passes AA on white). Muted links are for secondary navigation.

Calendar

The date picker panel. It picks one date at a time; a date range uses two fields (From and To), each with its own calendar. 40px round days; state comes from aria-pressed (selected), aria-disabled, data-outside and data-today.

Checkbox & radio

Native inputs inside their label, so clicking the text ticks them. Rows are at least 24px tall. Hover is a gray-50 fill; checked is blue-600; focus is a 2px white gap then a 2px blue-400 ring; disabled is flat gray.

Batch frequency

Code entry

One box per digit for verification codes, with the same edge and focus ring as inputs. (Not cc-code, which is inline code.)

Inputs

40px tall by default, with an inset 1px border so the field doesn't shift when the error border appears. cc-input--sm (36px) is only for dense spots: filter bars, a search inside a menu, popover or dialog list, and compact toolbars beside cc-btn--sm. Keep fields in one row the same height.

Option cards

A radio choice shown as a card (processing time, carrier, report options). The selected card gets a blue-600 border, a blue-50 tint and a filled radio.

Processing time

Switch

Turns one setting on or off. A <button role="switch" aria-checked> with a visible label and an On/Off word beside it. 40×24. Use aria-readonly="true" in view mode instead of disabled.

Off On Read-only Disabled

Segmented tabs

Switch between views of the same page or table. One 40px layout, so tabs line up with search fields and buttons in a toolbar. Table toolbars use the default look (white selected tab); page-level views use cc-tabs--brand (light blue selected tab). The selected tab is the one with aria-pressed="true".

Underline tabs

Sections inside a page, panel or drawer. Use segmented tabs for table views and toolbars. The selected tab has aria-selected="true".

Alerts

Inline messages at the top of a card or form. They never dismiss on their own. Use the message-only style for one-line sign-in notices.

Badges

Pill shaped by default, 12px text. Each status uses its 50 tint for the fill, 200 for the border and 700 for the text.

Featured icons

A decorative icon tile (Modern, gray) beside section headings, metric cards and empty states. It isn't clickable, so add aria-hidden="true" and let the heading name it. cc-featured-icon is md (40px); add --sm (32), --lg (48) or --xl (56).

Toasts

Short confirmation after an action, in one region at the top right of the page (cc-toast-region). Shown inline here.

Tooltips

A tooltip labels an icon button on hover (about 300ms) and on keyboard focus; Esc closes it. A toggletip holds extra details and opens on press, not hover. Both shown open here.

Settings group

A titled, bordered list of setting rows: label and help on the left, the control on the right. Used on the organization Settings tab (layout Version 3). In view mode, fields are read-only (not disabled) so they can still be reached.
